# SAi

**SAi (Search by AI)**

A practical term describing the evolution of information discovery,
where AI becomes the primary interface between humans and knowledge.

---

## Vision

Search is evolving.

From

Human → Search Engine → Website

to

Human → AI → Knowledge Source

SAi is an attempt to document and explain this transition.
